Daten & Datenschutz

Private JSON-Datei lokal laden

Wähle eine JSON-Datei auf deinem iPad. Die Datei wird im Browser eingelesen und nicht auf GitHub hochgeladen. Erwartet wird ein Array von Kartenobjekten oder ein Objekt mit cards-Array. Mögliche Felder: set, number, name, variant, quantity, avg7, trend, avg30, verified. Nur verified: true macht AVG7 für die Top-Liste frei.

Keine Datei geladen.

Was die App nicht macht

Keine automatische Excel- oder OneDrive-Verbindung. Kein Cloud-Login. Keine Speicherung deiner Sammlung auf GitHub. Beim Neuladen musst du die JSON-Datei erneut auswählen. Eine direkte Synchronisierung erfordert eine separate geschützte Lösung.
